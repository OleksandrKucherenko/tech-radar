What do the rings mean?

The AI Tech Radar is a list of technologies, complemented by an assessment result, called ring assignment. We use the following ring semantics:

  • ADOPT — Tools we should migrate to, from HOLD or other non-AI tools. These are the strategic defaults we actively promote and move toward.
  • VALUE — Tools that show clear value for new projects. We want to use them when the fit is good and the expected impact is high.
  • HOLD — Tools we can use and maintain, but will not choose for new projects.
  • SKIP — Tools we intentionally skip due to fit, maturity, cost, or strategic focus.
  • TRIAL — Tools we try in practice to evaluate them. We create accounts, run pilots, and validate real-world usage.
  • WATCH — Tool awareness: we start to see the tool and track signals before committing to hands-on evaluation.
